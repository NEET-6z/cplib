印刷向け・公式と定理中心。座標は平面直交座標、長さは正、角度は特記がなければラジアンとする。三角形の辺は $$a = |BC|,b = |CA|,c = |AB|$$、頂点は $$A = (x_{A},y_{A})$$ などとする。K, Sは面積

## 1. 基本・座標

- **ベクトル：** $$\overrightarrow{AB} = (x_{B} - x_{A},y_{B} - y_{A})$$
- **内積：** $$u \cdot v = u_{x}v_{x} + u_{y}v_{y} = |u||v|\cos\theta$$
- **外積（2Dの符号付き外積）：** $$u \times v = u_{x}v_{y} - u_{y}v_{x}$$。三角形の符号付き面積は $$S_{signed} = \frac{1}{2}((B - A) \times (C - A))$$。
- **原点中心の回転**（角度 $$\theta$$）：$$x^{\prime} = x\cos\theta - y\sin\theta,y^{\prime} = x\sin\theta + y\cos\theta$$
- **格子多角形のピックの定理：** $$S = I + \frac{B}{2} - 1$$。$$I$$ は内部格子点数、$$B$$ は境界格子点数。

## 2. 三角形

### 辺・角・面積

- **内角和：** $$A + B + C = \pi$$
- **三角不等式：** $$a + b > c,b + c > a,c + a > b$$
- **正弦定理：** $$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$
- **余弦定理：** $$a^{2} = b^{2} + c^{2} - 2bc\cos A$$（他の辺についても巡回置換で得られる）
- **面積：** $$K = \frac{1}{2}bc\sin A = \frac{1}{2}ca\sin B = \frac{1}{2}ab\sin C$$
- **ヘロンの公式：** $$s = \frac{a + b + c}{2},K = \sqrt{s(s - a)(s - b)(s - c)}$$
- **内接円・外接円との関係：** $$K = rs = \frac{abc}{4R}$$。$$r$$ は内接円半径、$$R$$ は外接円半径。
- **高さ：** $$h_{a} = \frac{2K}{a}$$
- **重心の性質：** 重心は各中線を頂点側から $$2:1$$ に内分する。重心から各辺までの距離の和は、対応する3辺を底辺とした高さの和の $$\frac{1}{3}$$ となる。

### 内心・内接円

- **内接円半径：** $$r = \frac{K}{s} = \frac{2K}{a + b + c}$$
- **内心の座標：** 頂点をベクトル $$A,B,C$$、対辺の長さをそれぞれ $$a,b,c$$ とすると、$$I = \frac{aA + bB + cC}{a + b + c}$$。ここで $$a = |BC|,b = |CA|,c = |AB|$$。各頂点に対辺の長さを掛ける。
- 内心から3辺を含む直線までの距離はすべて $$r$$。
- 内心は3つの内角の二等分線の交点。

### 外心・外接円

- **外心の計算：** 外心を $$O = (x,y)$$ とすると、$$|O - A|^{2} = |O - B|^{2} = |O - C|^{2}$$。
- 展開すると、$$2(B - A) \cdot O = |B|^{2} - |A|^{2},2(C - A) \cdot O = |C|^{2} - |A|^{2}$$。
- 3点が一直線上になければ、上の連立一次方程式で一意に求まる。直角三角形では外心は斜辺の中点。
- **外接円半径：** $$R = \frac{abc}{4K} = \frac{a}{2\sin A}$$

### 重心・垂心・中線

- **重心：** $$G = \left( \frac{x_{A} + x_{B} + x_{C}}{3},\frac{y_{A} + y_{B} + y_{C}}{3} \right)$$
- **中線長：** $$m_{a} = \frac{1}{2}\sqrt{2b^{2} + 2c^{2} - a^{2}}$$
- **垂心：** ベクトルまたは座標として $$H = A + B + C - 2O$$。$$O$$ は外心。右辺は各成分ごとに計算する。
- **オイラー線：** 外心 $$O$$、重心 $$G$$、垂心 $$H$$ は一直線上にあり、正三角形でない場合、$$OG:GH = 1:2$$。
- **オイラーの不等式：** $$R \geq 2r$$

### 三角形の重要定理

- **チェバの定理：** $$D \in BC,E \in CA,F \in AB$$ のとき、3本の線分 $$AD,BE,CF$$ が一点で交わる条件は $$\frac{BD}{DC} \cdot \frac{CE}{EA} \cdot \frac{AF}{FB} = 1$$。通常の内分の場合の式。延長上の点を扱う場合は、有向線分による符号規約を統一する。
- **メネラウスの定理：** 直線が三角形の3辺またはその延長と交わるとき、有向線分を用いた符号規約のもとで $$\frac{BD}{DC} \cdot \frac{CE}{EA} \cdot \frac{AF}{FB} = 1$$。有向比を使わない場合は、通常、絶対値の積が $$1$$ となる形で表す。
- 正弦定理・余弦定理・ヘロンの公式は、辺・角・面積の相互変換に使う。

## 3. 円

- **標準形：** $$(x - h)^{2} + (y - k)^{2} = r^{2}$$。中心 $$(h,k)$$、半径 $$r$$。
- **一般形：** $$x^{2} + y^{2} + Dx + Ey + F = 0$$。中心 $$\left( - \frac{D}{2}, - \frac{E}{2} \right)$$、半径 $$r = \sqrt{\frac{D^{2} + E^{2}}{4} - F}$$。
- **直径の両端が $$A,B$$ の円：** 中心は $$AB$$ の中点、半径は $$r = \frac{|AB|}{2}$$。
- **円周角の定理：** 同じ弧に対する円周角は等しい。中心角は、同じ弧に対する円周角の2倍。
- **タレスの定理：** 直径を見込む円周角は $$\frac{\pi}{2}$$。
- **接線：** 接点への半径と接線は垂直。円外の点から引いた2本の接線の長さは等しい。
- **点の冪：** 円と割線 $$PAB$$ について $$PA \cdot PB$$ は一定。接線 $$PT$$ の場合は $$PT^{2} = PA \cdot PB$$。
- **2円の交点判定：** 中心間距離を $$d$$、半径を $$r_{1},r_{2}$$ とすると、異なる2交点を持つ条件は $$|r_{1} - r_{2}| < d < r_{1} + r_{2}$$。等号の場合は接する。ただし同心円などの退化ケースは別途扱う。
- **円と直線の交点判定：** 円の中心から直線までの距離を $$d$$、半径を $$r$$ とすると、$$d < r$$ で2交点、$$d = r$$ で接する、$$d > r$$ で交点なし。
- **弦長：** 中心から弦までの距離が $$d$$ のとき、$$L = 2\sqrt{r^{2} - d^{2}}$$。
- **扇形**（角度 $$\theta$$ はラジアン）：弧長 $$L = r\theta$$、面積 $$S = \frac{1}{2}r^{2}\theta$$。
- **円環の面積：** $$S = \pi(R^{2} - r^{2})$$。

## 4. 多角形・四角形

- $$n$$ **角形の内角和：** $$(n - 2)\pi$$
- **凸多角形の外角和：** $$2\pi$$
- **対角線の本数：** $$\frac{n(n - 3)}{2}$$
- **円に内接する四角形：** 対角の和は $$A + C = B + D = \pi$$。
- **ブラーマグプタの公式：** 円に内接する四角形の辺を $$a,b,c,d$$、半周長を $$s = \frac{a + b + c + d}{2}$$ とすると、面積は $$K = \sqrt{(s - a)(s - b)(s - c)(s - d)}$$。
- **平行四辺形：** 隣接する辺ベクトルを $$u,v$$ とすると、面積は $$S = |u \times v|$$。対角線は互いの中点で交わる。
- **台形：** 上底を $$a$$、下底を $$b$$、高さを $$h$$ とすると、面積は $$S = \frac{(a + b)h}{2}$$。
- **正 $$n$$ 角形：** 外接円半径が $$R$$ のとき、面積は $$S = \frac{nR^{2}}{2}\sin\frac{2\pi}{n}$$。

## 5. よく使う距離・交点

- **2直線の交点：** 直線を $$P + tu,Q + sv$$ と表す。$$u \times v \neq 0$$ のとき、$$t = \frac{(Q - P) \times v}{u \times v},s = \frac{(Q - P) \times u}{u \times v}$$。$$u \times v = 0$$ なら平行または同一直線。
- **点から直線への射影：** 点 $$P$$、直線上の点 $$A$$、方向ベクトル $$v \neq 0$$ に対し、$$P^{\prime} = A + v\frac{(P - A) \cdot v}{v \cdot v}$$。
- **2点 $$A,B$$ を通る直線の方程式：** $$(y_{A} - y_{B})x + (x_{B} - x_{A})y + x_{A}y_{B} - x_{B}y_{A} = 0$$。
- **2直線の交点：** 2直線を $$A_{1}x + B_{1}y + C_{1} = 0,A_{2}x + B_{2}y + C_{2} = 0$$ とすると、行列式 $$D = A_{1}B_{2} - A_{2}B_{1}$$ が $$0$$ でなければ交点は一意に定まる。
- 最近点・垂線・円の接線では内積による直交条件を使う。交差判定では外積の符号を使う。
