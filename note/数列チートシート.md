# 高校数学B｜数列 チートシート

## 1. 基本事項

- 一般項：$$a_{n}$$
- 初項：$$a_{1}$$
- 第 $$n$$ 項までの和：$$S_{n}$$
- 隣接項の差：$$a_{n + 1} - a_{n}$$

**部分和から一般項**

$$a_{n} = S_{n} - S_{n - 1}(n \geq 2)$$

$$a_{1} = S_{1}$$

## 2. 等差数列

公差 $$d$$：隣り合う項の差が一定。

**一般項**

$$a_{n} = a_{1} + (n - 1)d$$

**公差**

$$d = a_{n + 1} - a_{n}$$

**第 $$n$$ 項までの和**

$$S_{n} = \frac{n(a_{1} + a_{n})}{2}$$

$$S_{n} = \frac{n\{ 2a_{1} + (n - 1)d\}}{2}$$

**等差中項**

$$b = \frac{a + c}{2}$$

## 3. 等比数列

公比 $$r$$：隣り合う項の比が一定。

**一般項**

$$a_{n} = a_{1}r^{n - 1}$$

**公比**

$$r = \frac{a_{n + 1}}{a_{n}}$$

**第 $$n$$ 項までの和（$$r \neq 1$$）**

$$S_{n} = \frac{a_{1}(1 - r^{n})}{1 - r}$$

または

$$S_{n} = \frac{a_{1}(r^{n} - 1)}{r - 1}$$

公比が $$r = 1$$ のとき：

$$S_{n} = na_{1}$$

**等比中項**

$$b^{2} = ac$$

## 4. Σ（シグマ）の公式

以下、$$n$$ は自然数とする。

| 項目       | 公式                                                              |
|------------|-------------------------------------------------------------------|
| 定数の和   | $$\sum_{k = 1}^{n}c = nc$$                                          |
| 自然数の和 | $$\sum_{k = 1}^{n}k = \frac{n(n + 1)}{2}$$                          |
| 平方和     | $$\sum_{k = 1}^{n}k^{2} = \frac{n(n + 1)(2n + 1)}{6}$$              |
| 立方和     | $$\sum_{k = 1}^{n}k^{3} = \left\{ \frac{n(n + 1)}{2} \right\}^{2}$$ |

**線形性**

$$\sum_{k = 1}^{n}(a_{k} + b_{k}) = \sum_{k = 1}^{n}a_{k} + \sum_{k = 1}^{n}b_{k}$$

$$\sum_{k = 1}^{n}ca_{k} = c\sum_{k = 1}^{n}a_{k}$$

**範囲の分割**

$$\sum_{k = 1}^{n}a_{k} = \sum_{k = 1}^{m}a_{k} + \sum_{k = m + 1}^{n}a_{k}$$

## 5. 階差数列

階差を $$b_{k} = a_{k + 1} - a_{k}$$ とおく。

**一般項**

$$a_{n} = a_{1} + \sum_{k = 1}^{n - 1}b_{k}$$

つまり、$$a_{n} = a_{1} + b_{1} + b_{2} + \cdots + b_{n - 1}$$

**使い方**

一般項が複雑な場合、$$a_{n + 1} - a_{n}$$ を計算して簡単な式にできないか調べる。

## 6. 漸化式

### ① 差が一定

$$a_{n + 1} = a_{n} + d$$

$$a_{n} = a_{1} + (n - 1)d$$

### ② 比が一定

$$a_{n + 1} = ra_{n}$$

$$a_{n} = a_{1}r^{n - 1}$$

### ③ 隣接項の差が $$f(n)$$

$$a_{n + 1} = a_{n} + f(n)$$

$$a_{n} = a_{1} + \sum_{k = 1}^{n - 1}f(k)$$

### ④ 定数項を含む一次漸化式

$$a_{n + 1} = pa_{n} + q(p \neq 1)$$

定数 $$\alpha = \frac{q}{1 - p}$$ を用いて、$$b_{n} = a_{n} - \alpha$$ とおく。

すると、$$b_{n + 1} = pb_{n}$$ となる。

したがって、$$a_{n} = \frac{q}{1 - p} + \left( a_{1} - \frac{q}{1 - p} \right)p^{n - 1}$$

## 7. 部分分数分解・望遠和

**基本形**

$$\frac{1}{k(k + 1)} = \frac{1}{k} - \frac{1}{k + 1}$$

**和の計算**

$$\sum_{k = 1}^{n}\frac{1}{k(k + 1)} = 1 - \frac{1}{n + 1} = \frac{n}{n + 1}$$

**一般形**

$$\frac{1}{k(k + m)} = \frac{1}{m}\left( \frac{1}{k} - \frac{1}{k + m} \right)(m \neq 0)$$

隣接する項が打ち消し合う形を作ると、和を簡単に計算できる。

## 8. $$k$$ と等比数列の積の和

$$r \neq 1$$ のとき、

$$\sum_{k = 1}^{n}kr^{k - 1} = \frac{1 - (n + 1)r^{n} + nr^{n + 1}}{(1 - r)^{2}}$$

したがって、

$$\sum_{k = 1}^{n}kr^{k} = \frac{r - (n + 1)r^{n + 1} + nr^{n + 2}}{(1 - r)^{2}}$$

## 9. 無限等比級数

初項 $$a$$、公比 $$r$$。

**収束条件**

$$|r| < 1$$

**無限和**

$$a + ar + ar^{2} + \cdots = \frac{a}{1 - r}$$

または、$$\sum_{k = 0}^{\infty}ar^{k} = \frac{a}{1 - r}$$

有限和は、$$S_{n} = \frac{a(1 - r^{n})}{1 - r}$$

$$|r| < 1$$ なら、$$n \rightarrow \infty$$ のとき $$r^{n} \rightarrow 0$$ となる。

## 10. 数学的帰納法

命題 $$P(n)$$ をすべての自然数について証明する方法。

1.  **初期段階：** $$P(1)$$ が成立することを示す。

<!-- -->

1.  **帰納段階：** $$P(k)$$ を仮定して、$$P(k + 1)$$ を導く。

この2段階が成立すれば、すべての自然数 $$n$$ について $$P(n)$$ が成立する。

## 11. 問題別・公式の選択

| 問題の特徴                 | 最初に試す方法                           |
|----------------------------|------------------------------------------|
| 隣り合う項の差が一定       | 等差数列                                 |
| 隣り合う項の比が一定       | 等比数列                                 |
| $$S_{n}$$ が与えられる       | $$a_{n} = S_{n} - S_{n - 1}$$              |
| $$a_{n + 1} - a_{n}$$ が簡単 | 階差数列・和の計算                       |
| $$a_{n + 1} = pa_{n} + q$$   | 定数を引いて等比型に変形                 |
| 分数の和で項が打ち消し合う | 部分分数分解・望遠和                     |
| $$1,k,k^{2},k^{3}$$ の和     | Σの基本公式                              |
| 無限に続く等比級数         | $$\text{|}r\text{|} < 1$$ を確認して無限和 |
| すべての自然数で成立する式 | 数学的帰納法                             |
